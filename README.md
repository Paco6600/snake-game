# 🐍 Snake Spiel

Ein klassisches Snake-Spiel, das komplett im Browser läuft.

## Spielen

Einfach die [index.html](index.html) öffnen oder das Spiel über GitHub Pages hosten.

**Steuerung:**
- Pfeiltasten oder **WASD**
- Auf dem Handy: Touch-Buttons

## Features

- Highscore wird im Browser gespeichert
- Modernes, dunkles Design
- Mobile-freundlich
- Keine Abhängigkeiten – pure HTML, CSS & JavaScript

## GitHub Pages aktivieren

1. Gehe zu **Settings → Pages**
2. Unter "Source" wähle **Deploy from a branch**
3. Branch: `main` / Ordner: `/ (root)`
4. Speichern – nach 1–2 Minuten ist das Spiel unter  
   `https://paco6600.github.io/snake-game/` erreichbar.
